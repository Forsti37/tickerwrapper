Auto-Ticker am Handy

Chrome blockiert Lesezeichen mit javascript: (darum about:blank#blocked). Deshalb nicht „Link lange drücken“.

Empfohlen unter Android: Firefox + Tampermonkey – einmal installieren, danach öffnet sich TW automatisch im Ligaportal-Editor.

Variante A – Firefox (einfach)

Firefox für Android installieren (Play Store).

In Firefox: Add-ons → nach Tampermonkey suchen → installieren.

Dieses Userscript installieren (in Firefox tippen):

Userscript installieren

Tampermonkey fragt „Installieren?“ → bestätigen.

In Firefox Ligaportal öffnen, einloggen, Demospiel:

Demospiel-Editor öffnen

Unten rechts erscheint TW → Overlay → speichern = direkt im Portal.

Variante B – Chrome (umständlich)

Lange drücken geht in Chrome nicht. Du musst ein normales Lesezeichen anlegen und die Adresse per Hand ersetzen.

Unten Code kopieren tippen.

Beliebige Seite als Lesezeichen speichern (Stern / Menü → Lesezeichen).

Chrome-Menü (⋮) → Lesezeichen → Lesezeichen antippen / bearbeiten (Stift) → Feld URL / Adresse komplett löschen → kopierten Code einfügen → Name TW → Speichern.

Ligaportal-Editor öffnen (Demospiel-Link oben), dann Lesezeichen TW aus dem Lesezeichen-Menü öffnen.

Die Ligaportal-App kann das nicht – nur Browser (Firefox empfohlen).
